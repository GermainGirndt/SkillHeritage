## Skill Heritage

### Benötigte Geräte und Technologien

Für die Entwicklung der App benötigen wir folgende Geräte und Technologien:
i) ein modernes Android-Smartphone (z.B. Samsung Galaxy S23 oder Google Pixel 8/8a)
ii) einen Private Virtual Server mit Storage (z.B. AWS EC2 mit AWS EBS/S3)
iii) Credits für die API von OpenAI (Whisper, Completions und VectorStores APIs)

### Fokus

Das Projekt soll sich auf den Usability-Aspekt “Learnability” fokussieren.
